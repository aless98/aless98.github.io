---
title: "🛠️ Released ML2InfraredTracking, an open-source Magic Leap 2 plugin for infrared tool tracking"
date: "2025-10-13"
---

The plugin tracks tools fitted with infrared retroreflective markers using the Magic Leap 2 raw depth sensor, with pose estimation running on the headset. [Source on GitHub](https://github.com/aless98/ML2InfraredTracking).
