Medical tasks that involve sustained physical contact -- probing, compression, scanning -- are hard to teleoperate because the operator cannot feel what the robot feels. This work builds an augmented reality framework that visualises the robot's state and interaction forces in the operator's view, and provides the interface through which the task is commanded.
